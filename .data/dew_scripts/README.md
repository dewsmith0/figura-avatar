This directory may be used in the future for host-only scripts.  
It should be installed in the "data" folder of Figura.  
You might want to hardlink these files (Linux):
`ln [avatar]/.data/dew_scripts/*.lua [figura]/data/dew_scripts`
Obviously, replace `[avatar]` with the path to this avatar, and `[figura]` with the path to your Figura folder.  

If you're on Windows, then go look it up, search "hard link command windows" or something. I don't use Windows.
